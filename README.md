# File Explorer Visualizer

A local Node.js app that visualizes folder disk usage in a colorful hierarchical tree.

## Features

- Browse folders on your Windows machine
- Display directory size and item counts
- Color-coded nodes based on space usage
- Click a node to open it in Windows Explorer
- Minimal, clean UI with depth controls

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the app:

```bash
npm start
```

3. Open in browser:

```
http://localhost:3000
```

## Notes

This app uses the local filesystem and Windows Explorer integration, so it runs locally on your machine rather than as a public static site.
